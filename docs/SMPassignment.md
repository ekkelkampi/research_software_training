**1. Description of software (purpose and intended user community)**

The software is a nominal joint moment estimator that uses data from the available sensors.
The model is a temporal convolutional network that can be trained and then employed as a moment estimator.
The software is meant to be used by people who aim to use a nominal joint moment estimator and to train it themselves with their own datasets. 
It needs to be developed since some changes are made to existing methods and we need it as a building block for a larger control architecture.

**2. Version control system**

The version control system that will be used is Git. There is no reason to manage version control in a different manner.

**3. Availability**

The code will be made available on GitHub, the research software directory and Zenodo. It can be accessed via the DOI provided with Zenodo.

**4. License**

The Apache-2 license will be used as it is the default.

**5. Measures to ensure the long-term sustainability of the software developed in the project**

The software will be developed to be used in a larger, overarching software suite used in other research projects. 
It will form a building block for a larger control architecture and will thus be updated when used in other research projects.

**6. Measures to support the software after completion of the project**

The software will be integrated into a research infrastructure and be used and updated in other projects.

**7. Resources needed to ensure the long-term usability and availability of the software**

The software will also be stored in the archives of the research group.

**8. Other measures to promote software longevity**

The software will also be integrated by the partner company and further developed for commercial use.
