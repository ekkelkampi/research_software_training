# Research Software Training – Assignment

This repository contains the code and supporting materials developed as part of the Research Software Management training at the University of Twente.

The project follows recommended research software management practices, with an emphasis on reproducibility, documentation, version control and FAIR principles.

## Folder Structure

The repository follows the recommended structure for R research software projects at the University of Twente.

```text
project-root/
├── code/                   # R scripts, functions and analysis logic
├── data/                   # Data used and generated by the analysis
│   ├── processed/          # Processed data
│   └── raw/                # Raw penguin data
├── docs/                   # Project documentation
├── img/                    # Image files (.png, .jpeg, .svg)
├── outputs/
│   ├── figures/            # Generated figures
│   └── reports/            # Generated reports
├── renv/                   # R environment files for reproducibility
├── tests/                  # Tests for code and functions
├── .Rprofile               # R profile
├── CHANGELOG.md            # Record of project changes
├── CITATION.cff            # Machine-readable citation metadata
├── LICENSE                 # Software license
├── README.md               # Project documentation
├── codemetadata.json       # Software metadata
└── renv.lock               # R package versions for reproducibility
```

## Installation

### Requirements

The following software is required to run the analysis:

- [R](https://www.r-project.org/) – statistical computing environment.
- [RStudio](https://posit.co/download/rstudio-desktop/) – recommended IDE for running and developing the R code.
- [Git](https://git-scm.com/) – for cloning the repository and version control.
- [renv](https://rstudio.github.io/renv/) – for managing and restoring the R package environment.

### Getting started

1. Clone this repository:

   ```bash
   git clone https://github.com/ekkelkampi/research_software_training.git
   ```

2. Open the project in RStudio by opening the `.Rproj` file.

3. Restore the required R packages using `renv`:

   ```r
   install.packages("renv")
   renv::restore()
   ```

4. Run the R script 00_sample_analysis.R located in the `code/` directory.

The `renv.lock` file specifies the package versions used in the project, allowing the R environment to be recreated.

## Reproducibility

This project uses [`renv`](https://rstudio.github.io/renv/) to manage R package dependencies.

The `renv.lock` file records the package versions used during development. To recreate the project environment, run:

```r
renv::restore()
```

When dependencies change, update the lockfile using:

```r
renv::snapshot()
```
